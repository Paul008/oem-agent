# Client Capture Pseudo-Element Text Design

Written 2026-06-05.

## Goal

Preserve simple CSS `::before` and `::after` text in the dashboard iframe Smart Capture path so labels and badges generated by pseudo-elements survive when a user captures a section from the Page Builder UI.

## Current State

The backend Cloudflare browser capturer already materializes simple pseudo-element text before serializing captured pages. The dashboard iframe capture injection still clones the selected live DOM directly:

- `cleanHtml(el)` posts raw cleaned HTML to the smart-capture parser.
- `tailwindHtml(el)` posts Tailwind-converted HTML for the raw HTML clone option.

Neither path currently reads computed `::before` or `::after`, so pseudo-rendered text can disappear from dashboard-side captures.

## Design

Add self-contained browser helpers inside `buildCaptureInjection()`'s injected script:

- `normalizePseudoElementContentForCapture(content)` accepts only quoted pseudo `content` strings and rejects `none`, `normal`, quote keywords, `url(...)`, `counter(...)`, `counters(...)`, and `attr(...)`.
- `pseudoElementInlineStyleForCapture(style)` emits a conservative inline style for materialized pseudo text: display, color, background-color, font-weight, font-size, line-height, margin, padding, border-radius, text-transform, and letter-spacing.
- `materializePseudoElementForCapture(src, cln, pseudo, includeStyle)` reads `window.getComputedStyle(src, '::before'|'::after')`, creates a span with `data-oem-pseudo` and `data-oem-pseudo-capture`, writes text through `textContent`, and inserts it at the beginning or end of the cloned element.
- `materializePseudoElementsForCapture(src, cln, includeStyle)` calls the before/after helper.

Wire the helpers into:

- `tailwindHtml()` after existing child recursion, with `includeStyle = true`; this avoids offsetting the source/clone child walk while preserving badge-like styling in raw HTML clone output.
- `cleanHtml()` after style stripping, with `includeStyle = false`; this gives the parser the missing text without changing the clean HTML styling contract.

## Safety

- The helpers remain fully self-contained because the injected script is serialized into the iframe.
- Materialized content uses `textContent`, not HTML assignment.
- Dangerous pseudo content kinds are ignored.
- Existing dangerous tag and event-handler cleanup remains unchanged.

## Testing

Add source-regression tests in `dashboard/src/composables/use-capture-injection.test.ts` that assert:

- The injected script contains the pseudo normalization/materialization helpers.
- The helpers use `window.getComputedStyle(src, '::' + pseudo)`.
- Materialized spans use `data-oem-pseudo`, `data-oem-pseudo-capture`, and `textContent`.
- `tailwindHtml()` materializes after child recursion with styles.
- `cleanHtml()` materializes without styles.

## Out of Scope

- Reconstructing pseudo-element layout geometry.
- Materializing pseudo images, counters, or attribute-driven content.
- Changing backend `PageCapturer`, which already has its own pseudo materializer.
- Responsive multi-width capture and post-JS-settle capture.
